STAGE 1 · INGESTION

Meet citizens where they already are.

Anyone in India can report infrastructure issues without downloading an app.

📱 WhatsApp Business API (Twilio) ✈ Telegram Bot (@jansetu_ai_bot) 💬 SMS ☎ IVR (missed call) 🌐 Web app

One shared pipeline

Every channel converges into ingestCitizenRequest(): translate → extract → resolve location → H3 cell → Firestore + priority-index tick — atomic Firestore transaction.

Live location resolution

India Post PIN lookup → Gemini district extraction → Nominatim geocoder → Wikipedia enrichment. Missing districts auto-provisioned.

STAGE 2 · AI

Gemini does the heavy lifting.

Translate

Voice note in Hindi / Tamil / Kannada → text.

TTS

Policy Copilot

gemini-flash-lite-latest (text, ~1000/day) + gemini-3.8-flash (multimodal) with 429/503 retry-with-backoff

STAGE 3 · PRIORITY INDEX

Transparent, tuneable, defensible.

PI = w₁·Demand + w₂·Deficit + w₃·Vulnerability

Same math on frontend (React) and backend (Node). 50/50 vitest cases guarantee parity — no drift between what the planner sees on the slider and what actually persists to Firestore.

Slide-to-simulate, no writes

POST /api/priority/simulate re-ranks all 15 districts in <150 ms without touching the DB. Sanction confirms → auto-recompute + save in transaction.

Every weight is visible. Every ranking is auditable. No black box.

STAGE 4 · POLICYMAKER LAYER

NITI-grade planning surface

Live hex map

H3 spatial grid over India, colored by PI. Click a district, see all its citizen requests.

AI Recommender

Top-N projects with matched scheme, estimated budget, beneficiary reach. Gemini polishes titles + justifications.

Trade-off simulator

Set 3 PI weights + sector filter → see instant re-ranking + AI-suggested target sector.

Policy Copilot

Natural-language Q&A over selected districts. Markdown answers with citations.

STAGE 5 · CLOSED LOOP

Every ₹ shows up on someone's phone.

Sanction fanout

Policymaker clicks Sanction Fund → backend finds every citizen request linked to that project's district+category → Telegram/WhatsApp/SMS dispatch fires in parallel.

Ad-hoc Telegram nudges

Searchable contact directory — every citizen who messaged the bot becomes searchable by name/district/complaint. One click prefills chat_id. Type → send → arrives.

Satellite audit

Pre/post construction imagery + AI verification score. Loop closes when the citizen sees the road they reported — not just a promise, but proof.

STAGE 6 · TRUST & ACCESS

Firebase Auth · Role-based · Open API.

Two identity types

Citizen — Google or email/password. Can submit requests, view public data.
Policymaker — email in POLICYMAKER_EMAILS allow-list. Can sanction, dispatch nudges, review satellite audits.

Server-verified guards

Every mutation checks a Firebase ID token via Admin SDK. Frontend UI hides restricted buttons; backend rejects with 403 if bypassed. UI reverts optimistic state on failure.

Open DPG surface — Swagger UI at /api/docs

Full OpenAPI 3.0.3 spec. 10 tagged groups, 25+ endpoints, live "Try it out" with Bearer token auth. Any state can consume this API — that's the DPG promise.
